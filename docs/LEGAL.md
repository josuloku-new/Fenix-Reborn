# Distribución de la versión 0.1

Se retiró el paquete con el ejecutable recompilado del juego. El EXE del asistente incluye la aplicación de preparación, sus fuentes de integración, textos y avisos; no incluye ISO, XEX, ejecutable recompilado, vídeos, texturas, doblajes ni DLC.

El asistente descarga herramientas desde sus proyectos oficiales y genera el código y el ejecutable del juego localmente desde la ISO seleccionada. Los archivos derivados, el SDK descargado, las bibliotecas de Microsoft y los guardados no se añaden al repositorio de fuentes.

Esto evita distribuir desde este proyecto una copia del ejecutable del juego. **No garantiza por sí solo la legalidad**: la reproducción, transformación y distribución del software están reguladas, y las excepciones para uso e interoperabilidad tienen condiciones. Deben revisarse también las licencias de herramientas y componentes.

Referencias oficiales: [Ley de Propiedad Intelectual, artículos 99 y 100](https://www.boe.es/buscar/act.php?id=BOE-A-1996-8930#a99), [Directiva 2009/24/CE](https://eur-lex.europa.eu/eli/dir/2009/24/oj?locale=es). Para publicar comercialmente o resolver dudas jurídicas concretas, conviene revisión profesional. Este documento describe el contenido técnico distribuido; no es una autorización de los titulares del juego.

Las condiciones de Microsoft se presentan mediante una casilla sin marcar, antes de preparar sus cabeceras y bibliotecas. No se redistribuyen esos paquetes con el asistente ni se aceptan sus condiciones silenciosamente.
